User Story: SauceDemo login flow (MCP)

As a user, I want to log in to the SauceDemo application so that I can see the products page.

Acceptance Criteria:
1. Open the SauceDemo login page (https://www.saucedemo.com/).
2. Enter the username: standard_user.
3. Enter the password: secret_sauce.
4. Click the login button to submit the form.
5. Verify that the Products page appears after login.
6. Ask the user to confirm and close the browser after the test is done.

MCP Notes:
- Each step is written for direct automation and code generation.
- Use Playwright MCP global config for execution.
- This story is suitable for file-driven, plain-English scenario automation.
- Keep using the story-mcp- prefix for future MCP scenarios.
