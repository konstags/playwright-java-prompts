2. Java version check and setup:
    - **First, check if Java is already installed and is version 17 or higher.**
       - Run: `java -version`
       - Parse the major version from output.
       - Tell the user exactly which Java version is currently installed.
    - Decision policy (strict):
       - If Java major version is exactly 17:
          - Keep Java 17 as-is and continue.
          - State: "Java 17 is installed and meets the minimum requirement."
          - Do **not** run `brew install`, `brew upgrade`, `brew update`, or any Java reinstall command.
       - If Java major version is higher than 17 (for example 21, 22):
          - Use the existing Java installation and continue.
          - State: "A higher Java version is installed; this is optional, not required for this project."
          - Do **not** recommend downgrading or switching to "latest".
          - Do **not** run `brew install`, `brew upgrade`, `brew update`, or any Java reinstall command.
       - If Java is missing or Java major version is below 17:
          - Explain that Java 17 is the minimum required to proceed.
          - Offer the user a choice to install Java 17 now.
          - If user approves, install OpenJDK 17 using Homebrew: `brew install openjdk@17`
          - Ensure your shell uses Java 17 (update PATH/JAVA_HOME only if needed).
    - Confirm Java 17+ is available by running: `java -version` again.

3. Create pom.xml with:
   - Java 17 compiler settings
   - Playwright Java (latest stable)
   - TestNG
   - Maven Surefire Plugin configured for TestNG
   Note: Allure reporting will be added in a later step — keep pom.xml minimal for now.

4. Create src/test/resources/testng.xml with a default suite that scans com.company.tests

5. Create .github/copilot-instructions.md referencing the skills folder, instructing Copilot to:
   - Always use the Page Object pattern for selectors and interactions
   - Always use TestNG @BeforeMethod / @AfterMethod for browser setup and teardown
   - Refer to skills/pw-test-patterns.md, skills/testng-fixtures.md, and skills/allure-annotations.md for patterns and conventions
   Note: Skills content is applied in Prompt 03b, so create this file with references now even if skills files are not present yet.

6. Create .github/prompts/ as a reusable prompt library containing:
   - test-generation.md
   - page-object-generation.md
   - test-utility-generation.md
   Note: These prompt files are helper templates for direct Copilot CLI usage and are not part of the mandatory 00-07 workflow.

7. Copy the remaining workflow prompt files from this repository's prompts folder into the new project's prompts folder:

   Rules:

8. Confirm the project structure was created and list the generated files.

9. After creation is complete, switch to the generated project and continue from there:
   - Run: cd ../playwright-java-automation
   - Confirm current folder is the generated project
   - Run prompts in this order: 03, then choose 04 (CLI exploration) or 05a (Jira test generation) or 05b (file-driven test generation), then 06, 07
